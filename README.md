# 🧾 Formulário de Cadastro

Este é um projeto de formulário de criação de conta desenvolvido com **HTML, CSS e JavaScript**, com foco em praticar estruturação de layout, estilização moderna e interatividade.

---

## 🚀 Funcionalidades

* ✅ Campos de cadastro (nome, sobrenome, data de nascimento, e-mail e senha)
* 👁️ Mostrar/ocultar senha ao clicar no ícone
* 🎨 Interface moderna e responsiva
* 🔘 Seleção de gênero com botões de rádio
* 📱 Layout adaptado para dispositivos móveis

---

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**
* **Font Awesome** (ícones)
* **Google Fonts (Poppins)**
